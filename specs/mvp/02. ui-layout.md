# UI Layout Reference

## Overview

The web app is a mobile-first single-page PWA built with React + Vite. All views are designed for a narrow viewport (mobile-first) and are intended to be installed as a PWA on iOS and Android.

Visual reference: the Twitch channel list sidebar — compact rows, live channels prominently first, minimal chrome.

## Authentication Gate

Unauthenticated users see only the login screen. No feature content is accessible without a valid session. The bottom tab bar is not rendered in the unauthenticated state.

## Login Screen

Full-screen, vertically centered layout:

- App branding (name / logo).
- "Connect with Twitch" primary action button.
  - Initiates `GET /api/auth/twitch/start`.

## Authenticated App Shell

A persistent bottom tab bar is rendered for all authenticated routes.

| Position | Label | Route |
|---|---|---|
| 0 | Channels | `/channels` |
| 1 | Alerts | `/alerts` |
| 2 | Account | `/account` |

Default tab on first load: **Channels**.

The active tab is visually indicated. Switching tabs does not reset scroll position (if feasible within the router).

## Views

### Channels Tab (`/channels`)

Twitch sidebar aesthetic: compact channel rows, live channels prominently above offline channels.

**Page structure:**

```
[Channels]                    [⟳ Sync]
──────────────────────────────
LIVE
  [row] [row] [row] ...
──────────────────────────────
OFFLINE
  [row] [row] [row] ...
```

**Ordering:**
- Live section: viewer count descending.
- Offline section: display name ascending.

**Channel row — live:**

```
╭──────────────────────────────────────╮
│ [●Avatar]  Display Name        [⚙️]  │
│            Category · 42K viewers    │
│            In [Category] for 1h 23m  │
╰──────────────────────────────────────╯
```

- Avatar is circular with a colored live indicator (dot on border or inline).
- Viewer count is formatted (e.g., `42K`, `1.2M`).
- Live duration is computed from `startedAt` at render time and formatted as `Xh Ym` or `Ym` if under an hour.
- `⚙️` config button opens the per-channel preference panel.

**Channel row — offline:**

```
╭──────────────────────────────────────╮
│ [Avatar]   Display Name        [⚙️]  │
│            Offline                   │
╰──────────────────────────────────────╯
```

- Avatar has no live indicator.
- Row is visually dimmer than live rows.

**Per-channel preference panel (bottom sheet):**

Opens from the config button on any channel row.

```
╭──── Display Name ────────────────────╮
│ Search categories...                 │
│ ┌──────────────────────────────────┐ │
│ │ Just Chatting                    │ │
│ │ Software and Game Development    │ │
│ └──────────────────────────────────┘ │
│                                      │
│ Saved for this channel               │
│  [Just Chatting ✕]                   │
╰──────────────────────────────────────╯
```

- Category search is debounced. Tapping a result adds a per-channel preference.
- Saved preferences are shown as removable chips or rows.
- Dismissible by swiping down or tapping outside.

### Alerts Tab (`/alerts`)

Global category preferences that apply across all followed channels.

**Page structure:**

```
[Alerts]
──────────────────────────────
[+ Add Category]
──────────────────────────────
Just Chatting                [✕]
Software and Game Dev        [✕]
──────────────────────────────
```

- "Add Category" opens a category search bottom sheet (same search UI as per-channel panel).
- Each row shows the category name and a remove button.
- Empty state: "No global alerts set."

---

### Account Tab (`/account`)

Connected account info, session management, and notification permission.

**Page structure:**

```
[Account]
──────────────────────────────
[Avatar]  Display Name
          Connected ✓
──────────────────────────────
Notifications
  Status: Enabled / Not enabled / Denied
  [Enable Notifications]          (if not granted)
  Go to browser settings to enable (if denied)
──────────────────────────────
[Sync Channels]
──────────────────────────────
[Reconnect Twitch]              (conditional — shown if session requires re-auth)
──────────────────────────────
[Log Out]
──────────────────────────────
```

- Reconnect prompt is shown only when the session is invalid or the API returns 401 mid-session.
- Log Out calls `POST /api/auth/logout` and redirects to `/login`.
