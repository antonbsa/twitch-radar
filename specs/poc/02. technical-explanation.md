# POC Technical Explanation

This document is historical. It explains what the proof of concept validated.

Decision reference: [ADR 0010](../../docs/decisions/0010-keep-poc-separate-from-mvp-architecture.md).

## What The POC Proved

The POC proved that a backend can send a Web Push notification to an installed PWA after an external event is simulated.

Validated sequence:

1. The user selects a predefined channel option.
2. The backend stores a waiting notification.
3. The backend starts a timer.
4. When the timer fires, the backend sends a Web Push message.
5. The browser push service delivers that message to the PWA service worker.
6. The service worker displays the notification on the device.

## MVP Relationship

The MVP replaces the simulated event source and historical POC storage/runtime with the architecture captured in the active MVP spec and ADRs.
