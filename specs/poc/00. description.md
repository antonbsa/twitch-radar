# POC Description

This directory contains historical proof-of-concept notes for browser Web Push validation.

Decision reference: [ADR 0010](../../docs/decisions/0010-keep-poc-separate-from-mvp-architecture.md).

## Validated Behavior

- A PWA can request notification permission.
- A PWA can create a Push API subscription.
- A backend can send a Web Push payload to that subscription.
- The service worker can display the notification.
