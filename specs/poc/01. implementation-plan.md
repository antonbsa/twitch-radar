# Notification POC Implementation Notes

This document is historical. It records the proof-of-concept validation target.

Decision reference: [ADR 0010](../../docs/decisions/0010-keep-poc-separate-from-mvp-architecture.md).

## Validated Flow

1. User opens the PWA on an iPhone.
2. User enables notifications.
3. User selects a predefined Twitch-like channel option.
4. Backend waits for the configured delay.
5. Backend sends a Web Push notification.
6. The installed PWA receives and displays the notification on iOS.

## Historical Scope

The POC covered:

- PWA UI.
- Service worker registration.
- Push subscription creation.
- Backend storage of push subscriptions.
- Backend scheduling of test notifications.
- Pending and triggered notification display.

The POC did not cover:

- Twitch OAuth.
- Twitch channel/category search.
- Twitch EventSub.
- User accounts.
- Durable MVP database setup.
- Background sync.
- Notification retries beyond basic error handling.
- Multi-device account synchronization.
